# Subahan Pathan — PortfolioA world-class futuristic personal portfolio with kinetic typography intro, **login-gated projects \& certificates**, full-stack auth, admin dashboard, and a premium dark theme.\---## Your Special Admin Access (pre-seeded)When you first start the server, an admin account is automatically created:|Field|Value||-|-||Email|`admin@portfolio.com`||Password|`Admin123!`||Role|`admin`|After logging in with these credentials, you will see an **Admin** badge in the top-right nav. Click it → choose **Dashboard** to open `/admin` where you can:* Add new projects* Edit existing projects* Delete projects* Add/edit/delete certificatesAll changes are live — no code editing required.\---## How Visitors See Your Site1. **Anonymous visitors** can browse: Hero, About, Skills, Experience, Education, Contact2. **Projects \& Certificates sections** show a **login wall** — visitors must sign in or create a free account to see your work3. **Only YOU** (with admin credentials) can add/edit/delete content from the dashboardThis creates exclusivity — your best work is a reward for engagement.\---## Quick Start (5 minutes)### 1\. Prerequisites* Node.js 20+* pnpm (or npm/yarn)* PostgreSQL 15+### 2\. Install```bashpnpm install```### 3\. EnvironmentCreate a `.env` file in the project root:```envDATABASE\\\\\\\_URL=postgresql://user:password@localhost:5432/portfolioSESSION\\\\\\\_SECRET=your-super-secret-key-change-me```### 4\. Database```bashpnpm --filter @workspace/db run push```### 5\. Start both services**Terminal 1 — API Server**```bashcd artifacts/api-serverexport PORT=8080export DATABASE\\\\\\\_URL=$DATABASE\\\\\\\_URLexport SESSION\\\\\\\_SECRET=$SESSION\\\\\\\_SECRETpnpm run dev```**Terminal 2 — Frontend**```bashcd artifacts/portfoliopnpm run dev```### 6\. Admin LoginOpen the site, click **Sign In** in the nav, enter:* Email: `admin@portfolio.com`* Password: `Admin123!`You will see an **Admin** badge. Click it → **Dashboard** to manage content.\---## File-by-File Guide### Frontend (`artifacts/portfolio/src/`)|File|Purpose||-|-||`App.tsx`|Root router. Wraps AuthProvider + wouter.
